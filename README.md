# livupos-carga

Distribuição temporária da carga inicial do LivupOS para os diretores da Liv Up. Arquivado depois da carga.

No Claude Code:

```
/plugin marketplace add livup-ai-projects/livupos-carga
/plugin install livupos-carga@livupos-carga
```

Depois, numa conversa nova: "quero montar o contexto de <área> no LivupOS". É preciso ter o conector do LivupOS ligado.

Gerado de livup/livupos-carga-inicial, commit 81aa011, versão 2026-11-27.1.
